# HorseRaceSimulator
My project is a customiable horse race GUI. you can edit the length and lanes of the race tracks to your liking by changing the race length and number of horses! This is donw using a slider and a Combo Box.
I did run into a graphical error where when the GUI first appears you need to adjust the size of the frame for all the correct buttons to appear. 
After you ahve selected the desired values for your racetrack, click the add Horse button. NOTE once the add horse button is clicked, you cannot edit the race track or number of horses anymore.

The add Horse button opens a seperate frame "Horse Customization!" with plenty of options to custimize your horse like coat colour, breed and symbol. For this panel I made use of textboxes and radio buttons. The drop down menu containing the optioins "horse 1" is what you will be selecting to edit each different horse. Once you have customized your dream horse, click create horse. Even after create horse is clicked the horse can still be edited. Once there is a horse created for the selected number of horses, click the start race button. NOTE the horses are no longer customizable, now the only way to change the attributes is by racing. 

When the start race button is clicked another frame called terminal should display, showing a live version of the race. 
The frame Race results is also displayed, giving you information about the horses and their race history. Providing the user with anough information to make a informed bet. After looking at the horse stats the user can choose to "place bets" by clicking the betting page button on the race results frame. The betting page displays the horse with the highest odds of winning along with a way to add the bet. The highest odds are calculated based on the confidence rating of the horses. The betting page also includs a drop down menu of all the Horse names for you to select and a text box where you can enter yur desired betting amount. 
After clicking the placebet button, another race will start and the winner is checked to see whether the user has won. if they have a celebratory message is displayed on a another frame, or a lost message is displayed.
the user can choose to start as many races as they would like. 
The user can also bet as many times as they would like
